# Données des cartes

`world_1914.geojson` et `world_1920.geojson` viennent du projet **historical-basemaps** d'André Ourednik :
https://github.com/aourednik/historical-basemaps (licence GPL-3.0).

`npm run maps` les découpe sur l'Europe, les simplifie et les projette en chemins SVG (`src/data/maps.json`).
Le fichier `src/data/maps.json` est un dérivé de ces données et reste sous la même licence (GPL-3.0).
